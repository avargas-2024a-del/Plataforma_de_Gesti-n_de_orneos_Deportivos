## HU-07 — Registrar Resultado con Marcador

**Como** árbitro o administrador, **quiero** registrar el resultado de un partido,
**para** que la tabla de posiciones se actualice automáticamente.

### Criterios de Aceptación
- [ ] Se puede registrar resultado indicando goles del equipo local y visitante
- [ ] Solo se puede registrar en partidos con estado 'programado'
- [ ] Al registrar, la tabla de posiciones se actualiza automáticamente
- [ ] Empate suma 1 punto a cada equipo; victoria suma 3 al ganador y 0 al perdedor
- [ ] Se puede editar el resultado mientras el torneo esté activo; la tabla se recalcula

### Tareas Técnicas
- Backend: CreateResultadoDto con validación de marcadores >= 0
- Backend: Lógica de actualización de tabla de posiciones en ResultadoService (transacción Prisma)
- Backend: ResultadoController (POST /partidos/:id/resultado, PUT /partidos/:id/resultado)
- Frontend: Formulario de resultado accesible desde la vista del partido
