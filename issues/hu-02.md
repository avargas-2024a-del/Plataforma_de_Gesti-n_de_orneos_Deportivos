## HU-02 — Editar y Eliminar Torneo

**Como** organizador, **quiero** editar o eliminar un torneo existente,
**para** corregir datos incorrectos o retirar torneos que no se llevarán a cabo.

### Criterios de Aceptación
- [ ] Se puede editar nombre, deporte, fechas y formato mientras no tenga partidos registrados
- [ ] Si se intenta editar un torneo con partidos ya jugados, el sistema retorna error descriptivo
- [ ] Se puede eliminar un torneo que no tenga equipos ni partidos asociados
- [ ] Si se intenta eliminar con equipos o partidos, el sistema retorna error claro
- [ ] Tras editar o eliminar, el listado se actualiza de inmediato

### Tareas Técnicas
- Backend: Validación de dependencias antes de eliminar en TorneoService
- Frontend: Página /torneos/[id] con botones Editar y Eliminar
- Frontend: Formulario de edición con datos precargados y confirmación de eliminación
